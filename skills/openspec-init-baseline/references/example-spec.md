# 资产处置单规范

## 目的

资产处置单规范定义了资产处置全生命周期的业务规则，包括处置单的创建、审核、执行与完成。该规范确保资产处置流程合规可控，防止资产重复处置，并为审计提供完整的处置记录追踪。

## 需求

### Requirement: 创建处置单

系统SHALL基于用户提交的处置请求创建新的资产处置单，并校验资产状态和处置原因。处置单状态MUST在创建时初始化为"草稿"。系统MUST NOT允许为已在处置流程中的资产创建处置单。

#### 场景: 成功为可用资产创建处置单

- **假设** 用户拥有"DISPOSAL_CREATE"权限
- **并且** 资产ID"ASSET-001"存在且状态为"可用"
- **并且** 资产"ASSET-001"不存在进行中的处置单
- **当** 用户提交处置单创建请求：
  | assetId      | ASSET-001 |
  | reason       | 损坏报废   |
  | disposalType | SCRAP     |
- **那么** 系统SHALL创建新的处置单
- **并且** 处置单状态SHALL为"草稿"
- **并且** 处置单SHALL关联到资产"ASSET-001"
- **并且** 处置单创建人SHALL为当前用户
- **并且** 处置单创建时间戳SHALL被记录

#### 场景: 资产已在处置流程中时拒绝创建

- **假设** 用户拥有"DISPOSAL_CREATE"权限
- **并且** 资产ID"ASSET-002"存在且状态为"可用"
- **并且** 资产"ASSET-002"已存在状态为"审核中"的处置单
- **当** 用户提交处置单创建请求：
  | assetId      | ASSET-002 |
  | reason       | 闲置淘汰   |
  | disposalType | TRANSFER  |
- **那么** 系统SHALL拒绝创建处置单
- **并且** 系统SHALL返回错误提示"该资产已在处置流程中"

#### 场景: 资产状态不可用时拒绝创建

- **假设** 用户拥有"DISPOSAL_CREATE"权限
- **并且** 资产ID"ASSET-003"存在且状态为"已处置"
- **当** 用户提交处置单创建请求：
  | assetId      | ASSET-003 |
  | reason       | 损坏报废   |
  | disposalType | SCRAP     |
- **那么** 系统SHALL拒绝创建处置单
- **并且** 系统SHALL返回错误提示"资产状态不允许创建处置单"

### Requirement: 审核处置单

系统SHALL支持对提交的处置单进行审核操作，审核通过后处置单状态MUST变更为"已审核"，审核不通过MUST将状态回退至"草稿"并记录审核意见。

#### 场景: 审核通过处置单

- **假设** 用户拥有"DISPOSAL_AUDIT"权限
- **并且** 处置单"DISP-001"状态为"待审核"
- **并且** 处置单关联的资产状态为"可用"
- **当** 用户提交审核通过操作：
  | disposalId | DISP-001 |
  | opinion    | 同意处置  |
- **那么** 处置单状态SHALL变更为"已审核"
- **并且** 审核意见SHALL被记录
- **并且** 审核人SHALL为当前用户
- **并且** 审核时间戳SHALL被记录

#### 场景: 审核驳回处置单

- **假设** 用户拥有"DISPOSAL_AUDIT"权限
- **并且** 处置单"DISP-002"状态为"待审核"
- **当** 用户提交审核驳回操作：
  | disposalId | DISP-002 |
  | opinion    | 处置原因不充分 |
- **那么** 处置单状态SHALL变更为"草稿"
- **并且** 审核意见SHALL被记录
- **并且** 系统SHALL允许重新提交审核

#### 场景: 无权限用户无法审核

- **假设** 用户不拥有"DISPOSAL_AUDIT"权限
- **并且** 处置单"DISP-003"状态为"待审核"
- **当** 用户提交审核操作
- **那么** 系统SHALL拒绝审核操作
- **并且** 系统SHALL返回权限不足错误

### Requirement: 执行处置

系统SHALL支持对已审核的处置单执行处置操作，执行完成后资产状态MUST变更为"已处置"，处置单状态MUST变更为"已完成"。

#### 场景: 成功执行已审核的处置单

- **假设** 用户拥有"DISPOSAL_EXECUTE"权限
- **并且** 处置单"DISP-001"状态为"已审核"
- **并且** 处置单关联的资产ID为"ASSET-001"
- **当** 用户执行处置操作：
  | disposalId | DISP-001 |
- **那么** 处置单状态SHALL变更为"已完成"
- **并且** 关联资产"ASSET-001"状态SHALL变更为"已处置"
- **并且** 处置完成时间戳SHALL被记录

#### 场景: 非已审核状态的处置单无法执行

- **假设** 用户拥有"DISPOSAL_EXECUTE"权限
- **并且** 处置单"DISP-004"状态为"草稿"
- **当** 用户执行处置操作：
  | disposalId | DISP-004 |
- **那么** 系统SHALL拒绝执行操作
- **并且** 系统SHALL返回错误提示"处置单状态不允许执行"
